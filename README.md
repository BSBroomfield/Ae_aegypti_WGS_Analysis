# Ae_aegypti_WGS_Analysis

1) RFMix
   
  These scripts are custom modifications to the AncestryGrapher Toolkit pipeline to map RFMix output onto chromosomes for _Aedes aegypti_. To be used in place of the .svg file and LAP.py script from Lisi and Cambell (2024)
  
  Please cite: 
  
  Lisi, A. and Campbell, M.C., 2024. AncestryGrapher toolkit: Python command-line pipelines to visualize global-and local-ancestry inferences from the RFMIX version 2 software. Bioinformatics, 40(11), p.btae616.
